3. Critical PLP technical rules


SSR everything. Filters and sort work via GET URL parameters; results render server-side.


Canonical: every parameter combination (price, provider, sort, location, q, seite=1) canonicals to https://campuna.de/inserate.


EXCEPTION category: the category filter NAVIGATES to the real category PLPs (/wohnmobile, /zelte, ...) instead of adding a parameter. Never create /inserate?kategorie=x as an indexable duplicate of a category page.


Pagination: the load-more button may use JS, but a real <a href="/inserate?seite=2"> stays in the HTML. Page 2+: self-canonical, title suffix "Seite 2", never noindex, link to previous and next page.


Schema: CollectionPage + ItemList (dynamic from rendered listings) + BreadcrumbList + FAQPage. NO Product schema on this overview; Product/Vehicle + Offer lives on listing detail pages only.


Listing card images: alt = listing title, loading="lazy", width/height set. First row may load eager.


Sold or expired listings never appear here; test listings never render in production.


Sort options: Neueste zuerst (default), Preis aufsteigend, Preis absteigend.


One H1 (hero). Results header "ALLE INSERATE" and all section headings = H2. Card titles = H3.
