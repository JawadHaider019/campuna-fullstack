0. Structure analysis of the approved design

The approved category design contains: header, category hero with search, subcategory chips, listing grid, load-more button, category link section and footer. That covers browsing but not ranking. The following SEO sections were missing and have been ADDED in this template. Build all of them.

A. Results header with count + sort

Above the grid: "X Inserate in dieser Kategorie" + sort dropdown. The count MUST equal the number of rendered cards (the current mockup shows "0" while cards are visible: bug). Sort changes never change the URL for crawlers (see rules).

B. Beliebte Suchen (popular searches)

Chip links to the highest-volume subcategory and filter searches inside this category. Internal linking + long-tail capture. Links go to real crawlable URLs, not JS filters.

C. Expanded SEO text block (~450 words)

The design has almost no text on category pages. A category PLP cannot rank without content. Added a structured block below the grid: intro, subcategory guide with links, buying advice, selling paragraph. H2/H3 structure, brand entities (Isabella, Dometic, DWT, EcoFlow, Ective, Victron, Mobicool).

D. Ratgeber teaser (3 guide cards)

Links category page to matching guide articles. Topical authority + internal links from money page to content hub and back.

E. FAQ section + FAQPage schema

4 category-specific questions. Visible accordion text matches the JSON-LD word for word (Google requirement). Targets PAA queries.

F. Pagination fallback + trust strip

"Weitere Angebote laden" is JS only: crawlers cannot click. Added a real link to /zubehoer?seite=2 below the button. Trust strip (direct contact, free private listings, safe trading) above the Ratgeber block.

G. Sell CTA band

Category pages target buyers AND sellers ("verkaufen" keywords). A dark green band with "Kostenlos inserieren" CTA before the FAQ. Converts supply-side visitors.

Also fixed from the mockup

Card meta must never run together: condition and subcategory are separate pills, price left and details link right. Test listings must never render on a live category page (the old Bubble site had a "test" listing indexed). Empty categories keep the page live and indexable: show "Aktuell gibt es hier keine Inserate. Sei der Erste und inseriere kostenlos." plus the CTA and the full SEO text block, never a bare empty page and never a redirect.

3. Category PLP rules (apply to all 9 categories)


Canonical: every filter, sort and page parameter (?sortierung=, ?preis=, ?zustand=, ?seite=) canonicalises to the base category URL. Exception: ?seite=2 and higher are self-canonical with title suffix "| Seite 2". Never noindex pagination.


Category navigation is never a filter parameter: a category click goes to the real category URL (/zubehoer, /wohnmobile ...), never to /inserate?kategorie=zubehoer. If parameter URLs exist for technical reasons they 301 to the clean URL.


Subcategory chips and Beliebte Suchen chips are real <a href> links to indexable PLPs. No onclick-only navigation anywhere in the category system.


Load-more needs the crawlable fallback link to ?seite=2. Every paginated page links to the next page. Listing detail URLs on page 2+ must be reachable as plain links.


Count in the results header equals the number of rendered cards. Test listings, drafts and sold/deleted listings never render and their URLs return 404 or 410 (sold: 301 to category after 30 days is also fine, pick one and keep it).


Empty category: page stays live and indexable with the empty-state message, sell CTA and full SEO text block. Never redirect, never noindex an empty category.


No Product schema on category pages (Google guideline: no Product markup on category/list pages). Allowed stack: BreadcrumbList + CollectionPage with ItemList + FAQPage.


ItemList in CollectionPage schema is generated dynamically from the first page of listings: position, name, url per item. Cap at the visible page size. The 3 items in the template are examples of the exact shape.


One H1 per page. Subcategory PLPs get their own H1/title/description following the same pattern (example: Vorzelte & Markisen gebraucht kaufen | Campuna).


All visible copy pure human German, du-form. No em dashes, no en dashes anywhere. Hyphens in compound words (Camping-Zubehör, Camping-Marktplatz) are correct German and stay.

6. Pre-launch verification checklist (run per category page)


Title 60 chars max, description 155 max, exactly one H1 (checked in this template: 44 / 152 / 1).


Zero em dashes and zero en dashes in visible copy (checked: 0).


All 3 JSON-LD blocks parse (validator.schema.org + Google Rich Results Test) and FAQ text matches visible text verbatim.


Canonical points to the clean base URL; ?sortierung= and filter URLs canonicalise; ?seite=2 self-canonical with "| Seite 2" title.


Subcategory chips and Beliebte Suchen resolve 200 to indexable PLPs; no chip links to a parameter URL.


Pagination fallback link visible and crawlable; results count equals rendered cards; no test listings.


Empty-state renders with SEO text when category has 0 listings (test with a filtered empty query).


Mobile: chips scroll horizontally, grid 1 column, tap targets 44px min.


Core Web Vitals: listing images lazy-loaded with width/height, LCP = hero H1 block, no CLS from chip row.
